# Local fonts

LANister Gate supports local Kalameh WOFF2 assets, but font binaries are intentionally not distributed in this repository.

Expected filenames:

- `KalamehWebFaNum-Regular.woff2`
- `KalamehWebFaNum-Medium.woff2`
- `KalamehWebFaNum-SemiBold.woff2`
- `KalamehWebFaNum-Bold.woff2`
- `KalamehWebFaNum-ExtraBold.woff2`

Only add font files if your license permits redistribution.
